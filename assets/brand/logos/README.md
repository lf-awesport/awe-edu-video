# AWE Sport Education logos

Four standalone logo variants recovered from the vector artwork embedded in `../guidelines/awe-edu-brand-guidelines.pdf`:

- `awe-sport-education-horizontal-color.svg`
- `awe-sport-education-horizontal-white.svg`
- `awe-sport-education-mark-color.svg`
- `awe-sport-education-mark-white.svg`

The source PDF was exported by Adobe Illustrator 30.7 on 2026-08-17 and has SHA-256 `2b4201e7caf121e5baa1464834651359969edf04c8de73fe288518a7ecefaa16`. The original logo geometry is stored as vector paths in PDF Form XObject 41. Extraction preserved those paths and the brand colors `#00339A` and `#33C5F3`; no tracing, font substitution, or rasterization was used.

White variants reuse the exact source geometry with white fills, matching the variants shown in the supplied guidelines. All SVGs have transparent backgrounds.

See `manifest.csv` for sizes and hashes.
