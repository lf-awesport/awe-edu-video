## Libre Franklin fallback

`LibreFranklin-Variable.ttf` and its italic counterpart cover weights 100–900. They are licensed under the SIL Open Font License 1.1 in `libre-franklin/OFL.txt`.

Libre Franklin is a temporary open-source substitute. It must not be presented as Franklin Gothic or treated as an exact brand match. Final brand-faithful output still requires licensed ITC Franklin Gothic Book, Demi, and Heavy files from the project owner, designer, Microsoft/Office entitlement, or an authorized font vendor.

See `manifest.csv` for exact source URLs, sizes, and SHA-256 hashes.
