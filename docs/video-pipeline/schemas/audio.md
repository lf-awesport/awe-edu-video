# Audio, TTS and captions / Audio, TTS e caption

**Candidate normative annex. Effective status inherits the parent specification (`in-review`); it becomes implementation authority only when that parent is approved.** Applicable requirement IDs: **AUDIO-001–AUDIO-005, COST-001, RIGHTS-001, QUALITY-004**. Every normative keyword maps to those IDs.

| Area | Normative contract (EN / IT) | Applicable requirement IDs |
|---|---|---|
| Semantic records | Versioned Script MUST remain semantic authority; LocalizedScript MUST map master units while permitting cultural/text/pacing adaptation; Utterance MUST be the smallest coherently recordable unit; VoiceCandidate MUST bind covered Utterance IDs and immutable audio Asset. / Script DEVE restare semantico; LocalizedScript DEVE mappare unità; Utterance DEVE essere unità minima; VoiceCandidate DEVE legare ID e Asset. | AUDIO-001 |
| TTS/human parity | TTS and human takes MUST share Candidate→provenance/rights→Selection contract. Import MUST verify/segment/align and report changed/missing/extra text; retakes MUST NOT overwrite. / TTS e take umani DEVONO condividere contratto; import DEVE verificare/allineare; retake NON DEVONO sovrascrivere. | AUDIO-003 |
| Voice/pronunciation | VoiceProfile MUST declare locale/accent/register/pace/energy/perceived age/pronunciation/consent constraints. Adapter degradation MUST be visible. Versioned PronunciationLexicon MUST map written term to approved phonetic/SSML rendition; unverified mandatory terms block approval. / VoiceProfile e lessico DEVONO contenere i campi; degradazioni visibili; termini obbligatori non verificati bloccano. | AUDIO-001, AUDIO-005 |
| Timing/captions | Selected VoiceCandidate MUST be actual build-timing authority; requested timing remains authored intent. A delta outside an approved, versioned scene/total tolerance MUST produce a timing proposal/change report and MUST NOT mutate an approved Storyboard. Provider word timing SHOULD be used only when validated; otherwise a planned forced-alignment/STT node MUST run. Captions MUST map Script IDs and Output Profile `burn-in|SRT|VTT|both|none`. / Candidate governa timing di build; delta fuori tolleranza DEVE creare proposta, non mutare Storyboard; alignment è nodo pianificato. | AUDIO-002, AUDIO-004 |
| Lanes and mix | Canonical lanes MUST be `voice-over|dialogue|music|ambience|sfx`; clips, automation/ducking/fades, overrides and stems MUST be explicit. Output Profile MUST declare loudness/true-peak/sample-rate/channel policy; Remotion receives only materialized clips and mix policy. / Lane, mix e policy DEVONO essere espliciti; Remotion riceve solo clip materializzate. | AUDIO-005 |
| Music/SFX/voice rights | Supplied, stock or generated music/SFX MUST follow Candidate/provenance/rights/Selection/materialization. Voice mode MUST distinguish stock/synthetic, identifiable imitation, reference upload, cloning and human performance, with authorized provider transfer and explicit purpose for cloning/transformation/training where applicable. Unknown mode/consent MUST block; a reference file MUST NOT imply consent. / Modalità voce, trasferimento e scopi di consenso DEVONO essere espliciti; unknown blocca. | AUDIO-005, RIGHTS-001 |
| Candidate profiles/cost | `fast` proposes one candidate/Utterance; `balanced` two for critical and one otherwise; `quality` permits at most three. The Execution Plan MUST resolve an integer `plannedCandidateCount` per Utterance before preflight. Extra Candidates require a new plan/economic binding/Reservation. Alignment/STT strategy, tool/model/version, confidence threshold, privacy and cost MUST also be planned; unknown required cost/capability blocks. / Il piano DEVE risolvere count intero e strategia alignment; candidate extra richiedono nuova autorizzazione. | AUDIO-003, AUDIO-004, COST-001 |
| Deliverables/validation | Final output MUST retain master mix, voice stem, music stem, SFX/ambience stem, required captions and manifest. Corruption, duration mismatch, clipping, out-of-policy loudness, unsupported format, unverified mandatory pronunciation, caption drift and missing rights/consent MUST block final. / Output DEVE conservare mix/stem/caption/manifest; i failure elencati DEVONO bloccare. | AUDIO-005, QUALITY-004 |
