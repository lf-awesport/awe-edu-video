# Quality and acceptance / Qualità e accettazione

**Candidate normative annex. Effective status inherits the parent specification (`in-review`); it becomes implementation authority only when that parent is approved.** Applicable requirement IDs: **QUALITY-001–QUALITY-005, APPROVAL-002–APPROVAL-003, SECURITY-007, COST-001**. Every normative keyword maps to those IDs.

| Area | Normative contract (EN / IT) | Applicable requirement IDs |
|---|---|---|
| Registry/outcomes | A machine-readable Quality Requirement registry MUST bind ID/version/status (`proposed|approved|superseded`), scope, method, unit/comparator or rubric, threshold/tolerance, severity, profiles, oracle/fixture refs, authority/source and expiry. Evaluator authority MUST be `Deterministic Check|Metric Evaluation|AI Assessment|Human Review`; outcome MUST be `pass|fail|warning|not-applicable|unknown|error`, separately severity `info|warning|blocking`. Missing/unapproved required threshold or unavailable validator MUST yield unknown/error and block. / Registry machine-readable DEVE definire oracle, soglie e autorità; threshold mancante o validator indisponibile blocca. | QUALITY-001, QUALITY-002, QUALITY-005 |
| Profiles | `fast|balanced|quality` MUST all fully check integrity, timing/caption/audio, output, legal/rights/Claims, safe-area and release invariants. Fast SHOULD sample AI on failures/critical scenes and review master/critical changes; balanced selected candidates/all boundaries/key scenes/master/variants; quality finalists/deep boundaries/scenes/master/all variants. / Tutti i profili DEVONO conservare invarianti; profondità DOVREBBE seguire la matrice. | QUALITY-003 |
| Scope/timing/cache | Requirements MAY scope candidate/layer/scene/transition/variant/RenderPlan/render/release and SHOULD run at the smallest useful artifact. Cache MUST match artifact, dependency, requirement, evaluator/tool/model, rubric/threshold, reference/baseline and profile hashes; roll-up MUST preserve localized findings. / Scope PUÒ variare; check DOVREBBERO essere precoci; cache DEVE avere hash completi; roll-up DEVE preservare finding. | QUALITY-001 |
| Checks | Final decode MUST check MIME/container/streams/codec/dimensions/aspect/fps/frame count/duration/timestamps/color/corruption/black/freeze. Audio MUST check loudness/peak/clipping/dropout/intelligibility/ducking/fades/channels; captions coverage/locale/text/cues/rate/lines/sync. Brand/UI MUST check logo/clear-space/palette/fonts/contrast/safe-area/verified UI. Continuity MUST check declared identity/environment/gaze/position/palette/light/motion/UI boundaries. Variants MUST check required scenes/Claims/CTA/layers/translation/timing/caption/layout/logo/attribution/output and semantic diff. / I check tecnici, audio, caption, brand, continuity e variant DEVONO coprire tutti gli elementi elencati. | QUALITY-001, QUALITY-003, QUALITY-004 |
| AI/sampling | AI Assessment MUST record model/version, rubric/input hashes, seed/sampling/confidence and predeclared run policy; it MAY create findings or open Human Review but MUST NOT override deterministic failure, turn unknown into pass or autonomously approve final creativity. Reruns MUST create immutable results with rationale; roll-up MUST NOT cherry-pick the most favorable applicable run. Human adjudication (`confirm|dismiss-false-positive|request-change|waiver-if-allowed`) remains separate. Expensive checks MAY sample deterministically; integrity/economic stream checks MUST inspect the full stream. / AI produce finding/escalation, mai Approval; rerun immutabili e niente cherry-picking. | QUALITY-002 |
| Non-waivable | Corrupt/unrenderable output, impossible/missing required Output Profile property, unusable/missing required audio/layer/caption/legal/attribution/CTA, wrong artifact hash, missing rights/consent, blocking unverified Claim and prohibited content MUST NOT be waived. / La lista NON DEVE essere derogabile. | QUALITY-003, APPROVAL-002, APPROVAL-003 |
| Review Package/report | Human decision MUST receive exact artifact/hash, scope/player/timecode, source intent, refs/baselines, localized findings, prior diff, decision consequences and remediation cost. Authoritative JSON report MUST include profiles/policies, requirements/results/findings/evidence, coverage/stale/unknown, Review Package, Waivers/Approvals, cost/duration and roll-up. / Review Package e report JSON DEVONO includere i campi elencati. | QUALITY-001 |
| Privacy/cost | External evaluators MUST receive bytes only under classification, rights/consent and provider/region/purpose/retention policy. Preflight MUST disclose outbound data and include compute/storage/proxy/evidence/API/alignment/render/sample/candidate/variant costs; required unknown evaluator cost blocks. / Evaluator esterni DEVONO essere autorizzati; preflight DEVE esporre dati/costi e unknown blocca. | SECURITY-007, COST-001 |

Full decode proves media integrity, not creative correctness. Freeze/black/content anomaly checks MUST use an intent-bound allow-list or produce reviewable findings rather than treating every detected interval as corruption. Measurable properties, probabilistic heuristics and human creative judgment MUST declare different oracles.
