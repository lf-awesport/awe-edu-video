# RenderPlan conceptual contract

**Candidate normative annex. Effective status inherits the parent specification (`in-review`); it becomes implementation authority only when that parent is approved. Not a compilable JSON Schema.** RenderPlan is immutable, canonical-JSON serializable, and identified by the hash of all resolved inputs.

Required: `schemaVersion`, `id`, `projectId`, Storyboard/Production Lock hashes, Variant ID as diagnostic identity only, OutputProfile (width, height, fps, codec/audio/caption policy), total frames, ordered scene intervals, transitions, renderer registry versions, layer frame intervals, content-addressed asset/font/caption staging references, audio lanes/mix, provenance refs, compiler/tool versions. The RenderPlan MUST be self-contained for resolution: Variant ID MUST NOT trigger runtime lookup or override. Optional: diagnostic labels, preview frame range, supported degradations. Runtime state, provider URLs, credentials, unresolved assets, and network dependencies are forbidden.

States are external: `planned→compiled→staged→rendered→verified`; content never mutates. Rational scene boundaries are accumulated before one conversion to integer frame intervals. Layer intervals are half-open. Transition semantics are explicitly `overlap` or `addition`. A layer exceeding authored duration MAY produce a build-resolved timing proposal and change report; it MUST NOT silently mutate a promoted Storyboard or bypass timing Approval. Staging path is relative to the plan hash; linked files MUST resolve inside the bundle to content-addressed targets and be hash-verified before render.

Studio controls MAY alter transient diagnostic props, but those values MUST NOT persist, produce an authoritative RenderPlan/Approval, or create a releasable artifact. Partial/frame-range renders are diagnostic artifacts and MUST NOT be promoted as Deliverables. Deterministic compile hash and media reproducibility are separate claims: final evidence MUST fully decode the media, while cross-machine byte-identical encoding MUST NOT be promised without a pinned toolchain test.

**Valid — non-normative:** 30 fps scene intervals `[0,150)`, `[150,240)`, selected assets by hash, local captions. **Invalid:** negative duration, overlapping scenes without Transition, cycle, font from Google Fonts at render time, generated asset lookup, edited Studio props treated as authority.
