# Glossary / Glossario

**Candidate normative annex. Effective status inherits the parent specification (`in-review`); it becomes implementation authority only when that parent is approved. Definitions do not prescribe implementation. / Allegato normativo candidato; lo status effettivo eredita dalla specifica padre e diventa autorità solo con la sua approvazione.**

| Term | Definition (EN) | Definizione (IT) |
|---|---|---|
| Brief | Immutable source collection expressing project intent; evidence, never executable instruction. | Raccolta sorgente immutabile dell'intento; evidence, mai istruzione eseguibile. |
| Normalized Storyboard Draft | Reviewable proposed structured interpretation of a Brief, not yet authority. | Interpretazione strutturata proposta e revisionabile del Brief, non ancora autorità. |
| Storyboard | Authoritative structured creative intent after required validation/approval, organized into Scenes without volatile state. | Intento creativo strutturato autoritativo dopo validation/approval, in Scene e senza stato volatile. |
| Source Reference | Trace from a Storyboard element, script line or Claim to precise Brief evidence. | Traccia da elemento, script o Claim a evidence precisa del Brief. |
| Assumption | Reviewable default or inference introduced because the Brief omitted a value. | Default o inferenza revisionabile introdotta perché il Brief omette un valore. |
| Claim | Factual, numerical, quoted, testimonial, legal or commercial assertion requiring evidence. | Affermazione fattuale, numerica, citata, testimoniale, legale o commerciale che richiede evidence. |
| Creative Proposal | Non-factual suggestion for narrative, visuals, pacing or presentation. | Suggerimento non fattuale per narrativa, visual, ritmo o presentazione. |
| Normalization | Traceable transformation from Brief to Draft that cannot promote itself. | Trasformazione tracciabile da Brief a Draft che non può auto-promuoversi. |
| Promotion | Controlled creation of a new immutable authoritative Storyboard from a validated Draft. | Creazione controllata di un nuovo Storyboard autoritativo immutabile da Draft validato. |
| Blocking Ambiguity | Unresolved required interpretation whose choice would materially change the Storyboard and blocks Promotion. | Interpretazione required irrisolta che cambierebbe materialmente lo Storyboard e blocca Promotion. |
| Normalization Report | Reviewable account of sources, assumptions, ambiguities, Claims, defaults, proposals and changes behind a Draft. | Resoconto revisionabile di fonti, assumption, ambiguità, Claim, default, proposte e cambi del Draft. |
| Voice Profile | Provider-independent intended voice attributes, pronunciation and consent constraints. | Attributi della voce desiderata, pronuncia e vincoli di consenso provider-independent. |
| Voice Candidate | Immutable TTS or human spoken interpretation; when selected, timing authority for covered units. | Interpretazione parlata immutabile TTS o umana; se selezionata, autorità timing delle unità coperte. |
| Localized Script | Versioned linguistic/cultural adaptation mapped to master Script units with permitted wording, pacing and duration differences. | Adattamento linguistico/culturale versionato mappato allo Script master con differenze ammesse. |
| Utterance | Smallest independently recordable/generatable spoken Script unit preserving coherent delivery. | Minima unità parlata di Script registrabile/generabile preservando interpretazione coerente. |
| Pronunciation Lexicon | Versioned locale-specific approved pronunciations for names, acronyms and domain terms. | Pronunce approvate versionate per locale di nomi, acronimi e termini di dominio. |
| Audio Lane | Semantic audio class sharing mix policy: voice-over, dialogue, music, ambience or sound effects. | Classe audio semantica con policy mix condivisa: voice-over, dialogue, music, ambience o sound effects. |
| Authority Snapshot | Immutable evidence that an identified actor/policy is authorized for a decision scope; identity alone is not authority. | Evidence immutabile che actor/policy è autorizzato per uno scope; identità sola non è autorità. |
| Approval | Immutable authorized actor/policy decision about one exact artifact version and scope. | Decisione immutabile di actor/policy autorizzato su versione e scope esatti. |
| Validation | Evaluation of a technical, legal, safety, quality or readiness condition; not a human decision. | Valutazione di condizione tecnica, legale, safety, qualità o readiness; non decisione umana. |
| Waiver | Authorized, scoped, expiring acceptance of a waivable failed Validation that remains a failure. | Accettazione autorizzata, scoped e con scadenza di Validation fallita derogabile, che resta failure. |
| Candidate Selection | Decision choosing one immutable Candidate for downstream use, separate from Approval. | Decisione che sceglie una Candidate immutabile per uso downstream, separata da Approval. |
| Release Manifest | Evidence bundle binding a deliverable to hashes, Output Profile, Approvals, Validation, Waivers, rights and freshness. | Bundle evidence che lega deliverable a hash, Output Profile, Approval, Validation, Waiver, diritti e freshness. |
| Releasable | Deliverable state whose current Release Manifest proves all publication/delivery conditions. | Stato del deliverable il cui Release Manifest current prova tutte le condizioni di pubblicazione/consegna. |
| Blob | Immutable binary content identified by cryptographic hash, without project meaning or rights. | Contenuto binario immutabile identificato da hash, senza significato o diritti progettuali. |
| Asset | Project-scoped meaning, purpose, provenance, sensitivity, lineage, cost and rights attached to a Blob. | Significato, scopo, provenienza, sensibilità, lineage, costo e diritti project-scoped associati a un Blob. |
| Rights Grant | Evidence-backed permission for explicit uses, media, territories, duration, attribution, modification and AI constraints. | Permesso con evidence per usi, media, territori, durata, attribuzione, modifiche e vincoli AI espliciti. |
| Consent Grant | Subject permission for specified likeness/voice/cloning/transformation use, scope, duration and revocability. | Permesso del soggetto per likeness/voce/cloning/trasformazione con scope, durata e revocabilità. |
| Asset Usage Manifest | Deliverable account of every Asset usage, location, lineage and relied-upon Grants. | Resoconto per deliverable di ogni uso Asset, posizione, lineage e Grant utilizzati. |
| Price Observation | Dated incomplete provider price evidence that informs planning but cannot authorize submit. | Evidence di prezzo provider datata/incompleta che informa il piano ma non autorizza submit. |
| Quote | Fresh provider-backed UnitQuote or BatchQuote for exact request and quantity scope in native units; not spending permission. | UnitQuote o BatchQuote fresca per richiesta e quantità esatte in unità native; non permesso di spesa. |
| Quote Binding | Immutable per-Candidate link to the fresh UnitQuote or BatchQuote whose scope covers it. | Legame immutabile per Candidate alla UnitQuote o BatchQuote fresca che la copre. |
| Cost Estimate | Versioned minimum/expected/maximum technical-resource projection with formulas, assumptions, confidence and Quotes. | Proiezione versionata minimum/expected/maximum di risorse tecniche con formule, assunzioni, confidence e Quote. |
| Reservation | Temporary claim against Budget before a potentially chargeable operation. | Impegno temporaneo sul Budget prima di un'operazione potenzialmente onerosa. |
| Budget | Authorized hard technical-resource limit for a scope/native unit; strictest nested limit governs. | Limite tecnico rigido autorizzato per scope/unità nativa; governa il nested più restrittivo. |
| Project Manifest | Human-editable versioned root declaration of project identity, inputs, policies, outputs and logical refs, without secrets/state. | Dichiarazione root versionata human-editable di identità, input, policy, output e ref, senza secret/state. |
| Runtime State | Project-local machine-managed execution record, not authoritative creative input. | Record di esecuzione locale gestito dalla macchina, non input creativo autoritativo. |
| Asset Store | Content-addressed shared store of immutable Blobs; project Asset contexts remain separate. | Store condiviso content-addressed di Blob immutabili; i contesti Asset progettuali restano separati. |
| Production Lock | Immutable portable snapshot of exact Storyboard, selections, policies, dependencies, provider resolutions and hashes for a build. | Snapshot portabile immutabile di Storyboard, selection, policy, dipendenze, risoluzioni provider e hash esatti di una build. |
| Execution Plan | Immutable proposal for reconciliation, side effects, cache, invalidations, Quotes, Reservations and expected outputs. | Proposta immutabile di riconciliazione, side effect, cache, invalidazioni, Quote, Reservation e output attesi. |
| Review Queue | Derived set of exact artifact versions awaiting human decision under current policy. | Insieme derivato di versioni artefatto esatte in attesa di decisione umana secondo policy current. |
| Deliverable | Named immutable render selected for delivery, not necessarily Releasable. | Render immutabile nominato e selezionato per consegna, non necessariamente Releasable. |
| Production Profile | Named policy preset controlling candidate counts, fallback tolerance, validation depth and approval defaults without changing intent. | Preset policy nominato che controlla candidate, fallback, profondità validation e approval senza cambiare intent. |
| Output Profile | Versioned technical/presentation constraints for dimensions, aspect, frame rate, codecs, audio, captions and layout. | Vincoli tecnici/presentazione versionati per dimensioni, aspect, frame rate, codec, audio, caption e layout. |
| Quality Requirement | Versioned scoped expected condition with method, threshold/rubric, severity and applicable profiles. | Condizione attesa versionata e scoped con metodo, soglia/rubrica, severity e profili applicabili. |
| Validation Result | Immutable evidence evaluating one Quality Requirement against exact artifact/dependency hashes. | Evidence immutabile della valutazione di un Quality Requirement su hash esatti artefatto/dipendenze. |
| Quality Finding | Localized observation tied where possible to Scene, Layer, time/frame, measurement, expectation, severity and remediation. | Osservazione localizzata legata ove possibile a Scene, Layer, tempo/frame, misura, atteso, severity e rimedio. |
| Review Package | Minimal evidence bundle for one human decision: exact artifact, intent, findings, references, changes and consequences. | Bundle evidence minimo per una decisione umana: artefatto, intent, finding, reference, cambi e conseguenze. |
| Master | Authoritative base narrative/timeline inherited but never implicitly mutated by Variants. | Narrativa/timeline base autoritativa ereditata ma mai mutata implicitamente dalle Variant. |
| Scene | Stable narrative unit containing relative-time Layers and requested/resolved duration. | Unità narrativa stabile con Layer a tempo relativo e durata requested/resolved. |
| Layer | Independently addressable typed technical/content unit within a Scene. | Unità tecnica/contenuto tipizzata e indirizzabile indipendentemente in una Scene. |
| Transition | Explicit timed edge between Scenes with overlap or addition semantics. | Edge temporizzato esplicito tra Scene con semantica overlap o addition. |
| Variant | Master-derived set of stable-ID overrides for locale, layout or output needs. | Insieme derivato dal Master di override per ID stabili per locale, layout o output. |
| BrandKit | Versioned semantic brand tokens, assets and usage rules. | Token semantici, asset e regole d'uso brand versionati. |
| Script | Versioned semantic spoken intent, distinct from recorded audio. | Intento parlato semantico versionato, distinto dall'audio registrato. |
| GenerationRequest | Immutable provider-neutral generative intent and constraints that may yield Candidates. | Intento generativo e vincoli immutabili provider-neutral che possono produrre Candidate. |
| Candidate | Immutable possible output with lineage, cost, rights and materialized content. | Possibile output immutabile con lineage, costo, diritti e contenuto materializzato. |
| RenderPlan | Fully resolved immutable renderer input with exact frame timing and hash-bound assets. | Input renderer immutabile completamente risolto con timing frame esatto e asset hash-bound. |
